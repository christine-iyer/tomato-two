# Disappearances Over Time

## Overview
This project visualizes data related to disappearances over time using D3.js. The application presents an interactive chart that allows users to explore trends and patterns in the data.

## Project Structure
- **index.html**: Contains the HTML structure of the web application, including metadata and links to external libraries.
- **script.js**: Handles the logic and functionality of the web application, utilizing D3.js for data visualization.
- **style.css**: Defines the appearance of various elements in the web application.

## Setup Instructions
1. Clone the repository to your local machine.
2. Open the project folder in your code editor.
3. Use the Live Server extension to run the `index.html` file.
4. Open your web browser to view the application.

## Usage
Once the application is running, you can interact with the chart to explore the data. Hover over elements for more information and use any available controls to adjust the view.
